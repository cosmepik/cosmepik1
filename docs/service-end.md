# cosmepik サービス終了の手順

- 告知日：2026年10月26日
- 終了日：2026年11月30日（`src/lib/service-end.ts` で一元管理）

## 1. 告知メール（全登録ユーザー宛）

**件名**：【重要】cosmepik サービス終了のお知らせ（2026年11月30日）

```
cosmepik をご利用いただいている皆さま

いつも cosmepik をご利用いただき、誠にありがとうございます。
このたび、運営上の理由により、2026年11月30日をもって
cosmepik のサービス提供を終了することといたしました。

■ スケジュール
・2026年10月26日：新規登録・プレミアムプランの新規申し込みを停止
・2026年11月30日：サービス終了（公開ページの表示・ログイン・編集を停止）

■ 登録データについて
サービス終了後、アカウント情報・プロフィール・アップロード画像・
コスメリスト・メイクレシピ等のデータはすべて削除し、復元できません。
必要なメイクレシピは、終了日までに編集画面の画像保存機能で保存してください。

■ 公開ページのリンクについて
終了日以降、cosmepik.me/ユーザー名 のページはサービス終了のご案内に切り替わります。
SNSのプロフィール等に掲載している場合は、差し替えをお願いいたします。

■ プレミアムプランをご契約中の方
自動更新を停止し、次回更新日以降の請求は行いません。

詳細：https://cosmepik.me/service-end
お問い合わせ：info@cosmepik.me

これまで cosmepik をご利用いただき、本当にありがとうございました。

cosmepik運営者
```

宛先は Supabase の `auth.users` のメールアドレス。LINE ログインのみのユーザーなど、メールアドレスがない人にはサイト上の告知（トップのバナーとダッシュボードのポップアップ）で通知する。

## 2. 告知日にやること

- [ ] このブランチをデプロイする（バナー・新規登録停止・プレミアム申し込み停止）
- [ ] Stripe：有効なサブスク（1件、¥560/月、次回請求 11/03）を「期間終了時にキャンセル」にする
- [ ] 告知メールを送る

## 3. 終了日（11/30）にやること

- [ ] 全ページを `/service-end` 相当の「終了しました」ページに切り替える（特商法・規約・プライバシーポリシー・問い合わせ先へのリンクは残す）
- [ ] Supabase の DB をバックアップ（`pg_dump`）してからプロジェクトを停止・削除する
- [ ] Stripe：Webhook エンドポイントを削除し、商品をアーカイブする（売上記録は帳簿として7年間保存）
- [ ] AdSense・楽天 API アプリ・LINE / Google / X のログイン連携アプリを削除する

## 4. 終了後

- [ ] バックアップは3ヶ月以内に削除する
- [ ] `info@cosmepik.me` とドメインは問い合わせ対応のため1年ほど残し、その後自動更新を切る
